# Python Learning

This repository contains a progressive set of Python lessons, examples, and
practice material. The lessons are organized into three phases and are
implemented primarily as Jupyter notebooks.

the learning sequence.

## Learning path

### First phase: Python fundamentals

| Notebook | Topics |
| --- | --- |
| [`session1a.ipynb`](first_phase/session1a.ipynb) | Python basics, identifiers and built-in data types, input, strings and f-strings, indexing, `if`/`elif`/`else`, loops, functions, lambda functions, list operations, classes, constructors, instance/class/static/abstract methods, encapsulation, inheritance, abstraction, method overriding, and duck typing |
| [`session2.ipynb`](first_phase/session2.ipynb) | Operators, conditional statements and loops, bitwise operators, membership operators, modules, and the `math` module |
| [`session3.ipynb`](first_phase/session3.ipynb) | Strings and string operators |
| [`session4.ipynb`](first_phase/session4.ipynb) | Lists, adding and deleting items, list methods, and list comprehensions |
| [`session5.ipynb`](first_phase/session5.ipynb) | Tuples and tuple operations, tuple functions, list-versus-tuple performance, sets and frozen sets, set operations, dictionaries, and dictionary comprehensions |

The first phase includes small programs for user input, arithmetic,
factorials, tables, string character and vowel counts, natural-number sums,
and common collection operations.

### Second phase: Functions, OOP, and files

| Notebook | Topics |
| --- | --- |
| [`session6.ipynb`](second_phase/session6.ipynb) | Functions as first-class objects, lambda functions, higher-order functions, `map`, `filter`, and `reduce` |
| [`session7.ipynb`](second_phase/session7.ipynb) | Object-oriented programming fundamentals: classes, objects, attributes, methods, constructors, and object behavior |
| [`session8.ipynb`](second_phase/session8.ipynb) | OOP concepts including line and distance examples, reference variables, encapsulation, collections of objects, and static versus instance variables |
| [`session9.ipynb`](second_phase/session9.ipynb) | Aggregation, inheritance, and method overriding |
| [`session10.ipynb`](second_phase/session10.ipynb) | File handling, writing and reading files, serialization, and deserialization |

The accompanying files demonstrate file and data handling:

- `sample.txt` and `sample2.txt` contain text-file examples.
- `sample.json`, `sample2.json`, and `sample3.json` contain JSON examples,
  including a student record and a list of values.
- `ss1.png` and `ss2.png` are image assets used with the second-phase
  exercises.

### Third phase: Exceptions, modules, decorators, and namespaces

| Notebook | Topics |
| --- | --- |
| [`session11.ipynb`](third_phase/session11.ipynb) | Exception handling, modules, and packages |
| [`session12.ipynb`](third_phase/session12.ipynb) | Decorators and namespaces |

## Practice

[`practice_pad.py`](practice_pad.py) is the repository-level Python practice
file. The notebooks contain the main guided examples and exercises, while
this file can be used for additional standalone practice.

## How to use

1. Install Python and Jupyter Notebook or JupyterLab.
2. Clone this repository.
3. Open the repository in Jupyter or VS Code.
4. Work through the notebooks in phase and session order.
5. Run each cell and modify the examples to reinforce the concepts.

The repository does not currently define a package dependency file; the
lessons use Python's standard library.
